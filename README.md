# 3dmigoto 一键自动化工具

> ⚠ **重要通知：该项目目前已暂停更新**

[3dmigoto 一键自动化工具](https://github.com/E5C8F/3dmigoto_automatic/)（又名 3dmigoto_Automatic 或 3dmigoto 一键综合版）是一个轻量化、绿色化、自动化、多功能化的智能工具，旨在解决 3dmigoto 使用过程中遇到的各种问题。

## 📋 前置要求

- **完整的游戏文件**：原神、星铁、鸣潮或绝区零（预计后期会支持更多游戏）
- **操作系统**：Windows 系统（已测试 Windows 11，非正版或有缺失的系统可能不支持）
- **运行库**：Visual C++ Redistributable for Visual Studio 2015-2022（通常安装游戏时会自动安装）

## 🚀 功能特色

### 核心功能
- **多版本支持**：内置并支持 3dmigoto-GIMI、3dmigoto.SRMI、3dmigoto WWMI、3dmigoto.ZZMI 的开发版和游玩版
- **多游戏支持**：支持原神、星铁、鸣潮、绝区零的 mod
- **版本切换**：游玩版和开发版自由切换
- **服务器切换**：原神官服和 B 服版本自由切换

### 自动化功能
- **路径自动搜索**：
  - 快速搜索：0~10 秒内搜索出大多数用户的游戏文件路径
  - 全局搜索：全面搜索任何用户的游戏文件路径
- **d3dx.ini 自动配置**：自动化配置 3dmigoto 所需文件
- **一键式启动**：无需手动多次点击
- **智能判断**：自动判断游戏并选择对应的 3dm 版本

### 稳定性和兼容性
- **防闪退机制**：
  - 分段释放：通过分段加载 Mods 文件夹内容缓解启动负荷
  - 网络控制：调控网络连接时机，错开负荷峰值
- **系统修复**：修复各种影响正常使用的系统问题
- **路径检测**：检测路径中的非法字符并提示用户
- **中文路径兼容**：支持中文路径环境
- **第三方兼容启动**：兼容第三方启动方式

### 实用工具
- **运行库安装**：支持安装缺失的运行库
- **鼠标键盘脚本**：支持自定义脚本功能
- **一键修复/重置**：不影响 Mods 数据的重置操作
- **后台执行**：支持后台运行模式
- **桌面快捷方式**：快速创建启动快捷方式
- **Mod 自动分类**：自动整理和分类 mod 文件
- **更新检测**：自动检测更新和接收公告
